# EL-001 · Raspberry Pi 5 case

Two-part printed case: a tray with standoffs and port openings, and a friction-fit lid with a lip.

| | |
|---|---|
| Status | designed, **not yet printed** (fit unverified) |
| Material | PETG (ASA if it goes on the boat) |
| Mass | base 30.0 g, lid 12.5 g |
| Outside | 91 × 62 × 30 mm assembled |
| Fasteners | 4 × M2.5 × 6 self-tapping (or M2.5 heat-set inserts: change `pilot_d` to the insert's hole) |

## Files
- `pi5-case.json`: **source of truth**, a SolidCraft command script. Edit this, then `./build.sh`.
- `pi5-case.sc`: the design (open in the SolidCraft app; regenerated by the build).
- `pi5-case.step`: for other CAD.
- `print.json` → `print/`: per-body 3MF/STL, already oriented (lid flipped, top face down).
- `drawing.json` → `out/drawing-*.svg|pdf|png`: dimensioned sheets.
- `out/`: renders and snapshots.

## Parameters (in the design)
`W` 91, `D` 62, `H` 28 (base height), `wall` 2, `floor_t` 2, `corner_r` 4, `standoff_h` 5, `pilot_d` 2.2,
`lid_t` 2, `lip_clr` 0.3, `lip_w` 1.5, `lip_h` 2.5.

Port openings and the lip are placed with plain numbers computed for a 91 × 62 case: changing `W`/`D`
moves the walls but **not** the port cut-outs. Re-derive them (see the table below) if you resize.

## Board data used (Pi 5, board origin = corner nearest USB-C)
| Feature | Board position | Opening |
|---|---|---|
| Mounting holes | (3.5, 3.5), 58 × 49 pattern, M2.5 | boss Ø6, pilot Ø2.2 |
| USB-C power | x 11.2, front edge | slot 11 × 6.5 |
| micro-HDMI 0 / 1 | x 25.8 / 39.2, front edge | slot 11 × 6.5 each |
| Ethernet | y 10.2, end edge | 17 × 14.5 |
| USB 3 / USB 2 stacks | y 29.1 / 47.0, end edge | 15 × 17 each |
| microSD | y 28, opposite end, under the board | slot 14 × 4 |
| GPIO header | along the far long edge | lid slot 54 × 6 |

**Check before printing:** port positions came from the published Pi 5 mechanical drawing from
memory, not measured. Print the base first (or a 0.2 mm-layer test of just the front and end walls)
and test-fit a real board. Not modelled: power-button access, fan/active-cooler clearance, PoE HAT.

## Print notes
- Base: open side up, no supports (the port tops bridge 11-17 mm).
- Lid: top face down (as exported), no supports.
- 0.2 mm layers, 3 walls, 15 % infill. If the lid is tight, set `lip_clr` to 0.4 and rebuild.
